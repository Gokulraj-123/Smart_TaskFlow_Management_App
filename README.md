# Smart_TaskFlow_Management_App
A simple and interactive Todo List web application built with Python and Streamlit, featuring task management, priorities, due dates, search, filters, and a dashboard.

TaskFlow is a simple and interactive Todo List web application built using Python and Streamlit. It helps users organize daily tasks, set priorities, track due dates, and monitor their progress.

#Features
Add new tasks
Set task priorities
Assign due dates
Mark tasks as completed
Edit and delete tasks
Search and filter tasks
View dashboard statistics
Track overdue tasks
Store task data using SQLite

#Technologies Used
Python
Streamlit
SQLite
SQL

#Getting Started
1. Clone the repository
git clone https://github.com/Gokulraj-123/Smart_TaskFlow_Management_App.git

2. Open the project folder
cd taskflow-todo-app

3. Install the dependencies
pip install -r requirements.txt

4. Run the application
streamlit run app.py
The application will open in your browser.

#Project Purpose
This project demonstrates beginner-friendly Python programming, web app development with Streamlit, and database operations using SQLite.
